## 二、签名修正（「哪里不对」）

1. **findStr 返回值**：官方 `ret, x, y` 三值（ret=命中序号 1-based），我们原来是 `x, y` 两值 → 已修正（未命中 `0, -1, -1`）。受影响调用方 smoke_android_ocr.py 已同步。
2. **findStr 多关键词**：官方 text 支持 `"打|开"` 竖线分隔多关键词 → 两端已实现。
3. **ocrText(x1,y1,x2,y2) 与官方 ocrText(handle,...) 的关系**：官方 OCR 是双体系——tesseract 句柄系（createOcr/releaseOcr/ocrText(handle,...)）+ PP-OCR 全局系（ocr/ocrj/ocrNew/ocrjNew）。我们的 ocrText 无 handle 直接识别，对应官方 PP-OCR 全局行为；handle 体系（见下表 P1）未实现。

## 三、语义核对确认无偏差的要点

- 触控/图色全局函数形态、BBGGRR 颜色序、`|` 多色 `-` 偏色分隔：与官方一致。
- sleep 单位=秒、mSleep=毫秒、rnd(a,b) 闭区间：与官方一致。
- writeFile 第三参 append、readFile 读全文、listDir 返回名称表、fileSize 字节：与官方一致。
- math/io/string/table/os 为 Lua 标准库（官方文档单列说明），LuaJ/Lua5.3 内置满足，无需自实现。
