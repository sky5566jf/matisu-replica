MatisuAuto · Phase 1 验证报告

PC Lua 引擎桥接真实设备 — 统一 API 落地（2026-08-30）

目标：让 PC 端 Lua 脚本（fengari 5.1 VM）通过 core.lua 统一 API 真正驱动两台测试设备， 而非仅打印调用。iOS 走局域网 8182 控制服务，Android 走 adb。

✅ 端到端验证通过：iOS 真机全流程触控后应用存活无崩溃；Android 模拟器同等驱动成功。

1. 架构与数据流

Lua 脚本 (demo.lua)
   │  调用 touch.tap / device.* / network.* / cipher.* / json.*
   ▼
core.lua 统一 API（被宿主覆盖为真实实现）
   ▼
runner.js (fengari C 回调)
   ▼
device_bridge.js ── 按 target 路由 ──┬─ iOS  : TCP 192.69.0.38:8182 → ControlServer → MatisuTouch* → IOKit HID
                                     └─ Android: adb -s 192.69.0.18:5555 shell input tap/swipe

2. 统一 API 覆盖情况

命名空间状态实现
touch.*真实tap/doubleTap/longPress/swipe/touchDown·Move·Up → 设备
device.*真实sleep / getScreenSize / getOSType / getDeviceName（截图等留待设备侧）
network.*真实httpGet / httpPost / download（curl）
cipher.*真实md5 / sha1 / base64（Node crypto；aes 待 Phase 3）
json.*真实encode / decode（fengari 表 ↔ JS 对象）
color.*桩findColor/findImage/ocr… 待 Phase 3 设备侧图色回传
node.*桩findNode/dump… 待 Phase 3 设备侧 UI 树回传

4. 关键修复点

  • JSON 数字变字符串：fengari 的 lua_isstring 对数字也返回 true，编码须先判 lua_isnumber，否则 1 会变成 "1"（已修）。
  • 目标切换优先级：MATISU_TARGET 环境变量须高于 devices.json 的 target 字段（已修）。
  • 坐标用 lua_tonumber 保留小数（屏幕点）。

5. 如何运行

# 默认 iOS 目标
cd replica/pc
NODE_PATH="C:/Users/Administrator/.workbuddy/binaries/node/workspace/node_modules" node runner.js

# 切到 Android 目标
MATISU_TARGET=android NODE_PATH=... node runner.js demo.lua

设备参数在 pc/devices.json；目标也可在文件里改 target 字段。
